# Limites de placas tectonicas

`PB2002_boundaries.geojson` contiene los limites globales del modelo PB2002 en
WGS84 (EPSG:4326). Se sirve como asset estatico del proyecto para no depender
de un CDN durante la ejecucion.

## Procedencia

- Trabajo original: Peter Bird, *An updated digital model of plate boundaries*
  (2003), DOI [`10.1029/2001GC000252`](https://doi.org/10.1029/2001GC000252).
- Conversion a shapefile: Hugo Ahlenius / Nordpil.
- Conversion a GeoJSON: contribucion de Craig Sterling al repositorio
  [`fraxen/tectonicplates`](https://github.com/fraxen/tectonicplates).
- Archivo fuente: `GeoJSON/PB2002_boundaries.json` en el commit
  [`339b0c56563c118307b1f4542703047f5f698fae`](https://github.com/fraxen/tectonicplates/blob/339b0c56563c118307b1f4542703047f5f698fae/GeoJSON/PB2002_boundaries.json).
- Descargado: 2026-09-15.
- Modificaciones locales: ninguna; solo se cambio la extension a `.geojson`.
- SHA-256: `42b3e0876a7e40f133e958ba7ab85f8851b5c693a046fbc3b138e7751863d92a`.
